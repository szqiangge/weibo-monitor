# 微博云端监控系统 (UID:2241280342)

通过 GitHub Actions 每日自动监控微博用户（UID: 2241280342）的更新，不依赖本地电脑开机。

## 工作原理

1. **每天北京时间 04:30 / 10:00 / 23:00**，GitHub Actions 自动启动
2. 脚本通过 RSSHub 源 + 移动端 API 双端抓取目标用户的最新微博
3. 对比上次记录，找出新增微博
4. **删除检测**：对历史记录中未出现在本次抓取的近期微博（30天内），访问其详情页验证是否被删除/隐藏
5. 如果有新微博或检测到删除，自动发送邮件通知（含微博全文、删除报告和链接）
6. 监控记录自动提交回仓库，持久保存

## 删除检测功能 (v5.1+)

系统会自动检测目标用户是否删除或隐藏了之前已抓取的微博：

- 每次运行时，为所有已见微博更新 `last_seen` 时间戳
- 对"上次见过但本次未返回"的近期微博（30天内），通过 Playwright 访问其 m.weibo.cn 详情页验证存在性
- 检测到删除时，自动截图保存删除证据
- 删除记录持久化存储在 `weibo_records.json` 的 `deleted_posts` 字段中
- 分析报告PDF中包含"删除检测报告"章节
- 记录汇总PDF中包含"已删除/隐藏微博记录"章节，保留原始内容
- 邮件通知中包含删除计数

## 首次运行

首次运行时会将当前所有可见微博作为基线记录，并发送一封"监控已启动"的确认邮件。之后仅在有新微博时发送通知。

## 需要配置的 GitHub Secrets

在仓库 Settings → Secrets and variables → Actions 中添加：

| Secret 名称 | 说明 | 本项目填写的值 |
|-------------|------|----------------|
| SMTP_SERVER | SMTP 服务器地址 | smtp.139.com |
| SMTP_PORT | SMTP 端口 | 465 |
| SMTP_USER | 发件邮箱地址 | 13902474300@139.com |
| SMTP_PASS | 邮箱授权码（非登录密码） | （139邮箱授权码） |
| NOTIFY_EMAIL | 接收通知的邮箱 | 13902474300@139.com |

## 手动触发

在仓库 Actions 页面，选择 "每日监控微博 (UID:2241280342)" 工作流，点击 "Run workflow" 可手动触发一次检查。
